- Full bilingual architecture supporting **English (`en`)** and **Simplified Chinese (`zh` / 简体中文)**.

  2. `Bliss Dhigurah` (Dhigurah, Alif Dhaal Atoll)

- Dynamic XML Sitemap (`/sitemap.xml`), `robots.txt`, custom HTML Sitemap (`/sitemap-page`), site-wide Search (`/search`), custom 404/Error/Loading states, and Schema.org JSON-LD (`TravelAgency`, `LodgingBusiness`, `TouristDestination`, `Article`, `BreadcrumbList`).
